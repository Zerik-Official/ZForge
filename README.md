# ZForge

Modern desktop launcher for World of Warcraft 3.3.5a.

Features:
- Client download / install
- File verification & repair
- Patch management
- Addon management
- Config.wtf editor
- Discord Rich Presence
- Self updater

## Stack

Backend:
- Python
- pywebview
- Pypresence

Frontend:
- React
- TypeScript
- Tailwind CSS
- Vite
